## ❓ راپیدو چیه؟

**Rapido VPN** یه برنامه‌ی فیلترشکن برای اندروید هست که با **لینک اشتراک (Subscription)** خودتون وصل می‌شه. کافیه لینک اشتراکتون رو وارد کنید؛ برنامه سرورها رو خودش می‌گیره، پینگ‌شون رو نشون می‌ده و با یه لمس وصل می‌شید.

هسته‌ی اتصال **Xray-core** هست.

## 📥 دانلود

آخرین نسخه رو از صفحه‌ی **[Releases](../../releases/latest)** بگیرید.

| فایل | مناسب برای |
|------|-----------|
| **universal** | همه‌ی گوشی‌ها (حجم بیشتر) — اگه مطمئن نیستید این رو بگیرید |
| **arm64-v8a** | اکثر گوشی‌های امروزی (حجم کمتر) |
| **armeabi-v7a** | گوشی‌های قدیمی ۳۲ بیتی |
| **x86_64** | شبیه‌ساز و دستگاه‌های x86 |

### ❓ کدوم فایل رو بگیرم؟

- مطمئن نیستید؟ ← **universal**
- گوشی جدید (مثلاً سامسونگ، شیائومی، ...) ← معمولاً **arm64-v8a**
- نصب نشد یا خطای سازگاری داد ← **universal** رو امتحان کنید
